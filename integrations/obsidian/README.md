# Doc Bridge for Obsidian

Desktop companion for reviewing drift in a vault. Build with `npm install && npm run build`, then copy `main.js`, `manifest.json`, and `styles.css` into a vault using `node scripts/install.mjs <vault-path>`. Pick a **Source** in the plugin settings, then use **Refresh from doc-bridge**.

## Source: doc-bridge vault (default)

For a vault generated by doc-bridge. Set the repository root; the plugin runs `ak-docs vault export --findings --json`. It does not run `ak-docs index`, which fails on purpose while the publication gate blocks drift.

The plugin reads tags and titles from Obsidian's metadata cache. Graph colours come from the exporter's `.obsidian/graph.json`; in this mode the plugin does not modify that file.

## Source: custom command

For hand-written vaults that must not be rewritten. Set **Command** (an executable and arguments, no shell syntax) and optionally **Working directory** (default: the vault root). The command prints JSON:

```json
{ "ok": true, "notes": 120, "findings": 2, "stale": [
  { "file": "repos/api.md", "paths": ["src/send.ts"], "repo": "api", "recorded": "a1b2c3d", "current": "e4f5a6b" }
] }
```

`file` is vault-relative; `repo`, `recorded` and `current` are optional. With `"ok": false` and an `error`, the plugin shows the error. The default command is `node scripts/refresh-brain.mjs --json`, which is what the AgentsKit brain vault ships.

In this mode the plugin never edits notes. It shows drift as:

- a status bar item, `doc-bridge · N stale` or `doc-bridge · in sync`;
- the findings view, one entry per stale note with its changed paths and `recorded → current`; click to open the note;
- explorer markers on stale notes;
- graph colouring: one amber (`#e3b341`) colour group, placed first in `.obsidian/graph.json`. The plugin only edits its own group, identified by a marker term in its query; every other key and group is kept, the file is written atomically, and the group is removed when nothing is stale. Open Graph views are reopened after a change. At most 400 notes are coloured; a notice says when the list was capped.
