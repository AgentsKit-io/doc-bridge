CLI: the command surface is now declared with commander, and three UX changes.

- Command names, `ak-docs --help`, and `ak-docs <command> --help` are generated by commander from one table. The help text changed; exit codes did not, and a parity suite pins them.
- `ask`, `search`, and `query` answer from a stale index by rebuilding it in memory (never written), with one stderr note. If the rebuild fails, the stale index on disk answers with a warning. `--no-refresh` keeps the strict failure.
- `gate run --text` prints one line per gate and the pending reference findings. JSON stays the default.
- Text output shows paths relative to the project root. `ak-docs index --text` is new; JSON output is unchanged.
