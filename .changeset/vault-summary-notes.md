Vault export can write notes people can read: `vault.content: "summary"` opens each note with a short summary (document description or first paragraph, module leading comment, package description, key counts) and groups relations under readable headings such as "Documented by" and "Imported by". `vault.exclude` keeps matching files, and knowledge derived only from them, out of the vault.
