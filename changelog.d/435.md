feat: `retrieval.benchmark.exclude` leaves globs (tests) out of the corpus `ak-docs bench retrieval` and the doctor measure, so new test files no longer shift BM25 statistics and source rankings
Ranking lets a weaker lexical anchor take graph proximity from a stronger one over a documentation edge, so a page named for the query is no longer outranked by a body-only mention linked to the top hit. Over an import, two anchors corroborate each other only when the importer is the stronger one, so a module's tests never rise above, or lift, the module the query asked for.
