# Integrations

`integrations/obsidian` is the Obsidian desktop plugin, with its own `package.json`, build config
(`esbuild.config.mjs`) and tests. Its entry point is `integrations/obsidian/main.ts` and shared logic
lives in `integrations/obsidian/src/core.ts`.

It reviews drift in a vault from one of two sources: a vault generated by `ak-docs vault export
--findings --json`, or a user-supplied command that prints JSON. See `integrations/obsidian/README.md`
for the settings and the stale-note output contract.
